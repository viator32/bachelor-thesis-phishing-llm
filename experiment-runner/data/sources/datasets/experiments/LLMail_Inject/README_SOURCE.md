# LLMail-Inject
Role: prompt-injection robustness evaluation and source of explicitly annotated defensive injection examples.
Dataset: https://huggingface.co/datasets/microsoft/llmail-inject-challenge
Documentation/analysis: https://github.com/microsoft/llmail-inject-challenge-analysis
Paper: https://arxiv.org/abs/2506.09956
Published dataset: 208,095 unique adaptive prompt-injection submissions from 839 participants.
Important: prompt-injection labels are NOT phishing labels. Map contains_prompt_injection separately; is_phishing requires independent annotation.
